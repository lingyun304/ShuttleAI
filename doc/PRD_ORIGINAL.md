## 一、项目概述

### 1.1 项目背景

短剧市场爆发式增长，传统短剧制作成本高（单集数万至数十万元）、周期长（数周至数月）、团队规模大（30-50人）。AI视频生成技术的成熟使得"一人短剧工作室"成为可能，极大降低了创作门槛和制作成本。

### 1.2 产品定位

**一站式AI短剧制作平台** —— 用户仅需提供一句话创意或上传小说/剧本，平台通过AI Agent协同完成从剧本生成、分镜设计、角色场景资产生成、视频制作到配音字幕的全流程，输出可直接发布至抖音、快手、小红书等平台的竖屏高清短剧。

**核心Slogan**：AI编剧 + 导演，一人短剧工作室

### 1.3 目标用户

| 用户群体 | 描述  | 核心需求 |
| --- | --- | --- |
| 个人创作者 | 无团队、无设备的短剧爱好者 | 零门槛创作，低成本试水 |
| MCN/内容团队 | 批量生产短剧的内容公司 | 高效批量生产，稳定质量 |
| 网文IP持有者 | 拥有小说/网文版权的个人或公司 | 快速将文字IP视频化 |
| 海外内容创作者 | 面向海外市场的短剧制作方 | 多语言支持，跨文化适配 |

### 1.4 核心价值主张

-   **零门槛**：无需影视专业背景，一句话即可开始创作
    
-   **全流程**：剧本→分镜→资产→视频→配音→字幕，一站完成
    
-   **极低成本**：单集约200元，较传统制作降低95%以上
    
-   **高效产出**：单人日产能约30集，一人一机7天可完成50集短剧
    
-   **品质可控**：AI角色一致性、物理真实感接近实拍

## 三、核心功能模块详细需求

## 四、非功能性需求

| 指标  | 要求  |
| --- | --- |

### 5.2 关键技术选型建议

| 领域  | 推荐方案 | 说明  |
| --- | --- | --- |
| **前端** | Next.js 14+ / React 18+ | SSR提升SEO，React生态丰富 |
| **UI框架** | TailwindCSS + Shadcn/UI | 快速构建美观界面与暗黑/亮色主题 |
| **后端框架** | Python (FastAPI) / Node.js (NestJS / Next.js API) | API及AI编排服务 |
| **数据库** | PostgreSQL + Prisma ORM / Redis | 关系数据用PG，缓存/任务队列用Redis |
| **模型驱动层** | Provider Driver Pattern (适配器模式) | 统一封装 LLM/Flux/Kling/CosyVoice，支持 Mock 沙盒测试 |
| **通信机制** | SSE (Server-Sent Events) / WebSocket | 实时推送视频渲染与分镜生成进度 |
| **音视频引擎** | FFmpeg (后端合成) + HTML5 Video/Canvas (前端预览) | 提供实时微剪辑与全集渲染导出 |
| **文件存储** | 阿里云OSS / AWS S3 / MinIO | 存储用户上传及生成的音视频/图片资产 |

### 5.3 模型适配器与沙盒驱动 (Model Adapter & Mock Sandbox)
- **统一 API 接口设计**：定义抽象 Driver 接口（包含 `generateScript`, `generateImage`, `generateVideo`, `synthesizeAudio`），降低后期更换或增加新 AI 模型（如 Seedance 2.0 / Kling / Vidu）的技术耦合度。
- **Mock/Sandbox 机制**：内置轻量级开发/测试沙盒驱动，开发阶段无需依赖高成本外网 AI API 即可高保真模拟视频生成进度与资产返回。
- **降级与自动重试**：多 API 服务商备选重试（如 Seedance 响应超时时自动降级切换至 Kling），确保渲染任务的高可用。

### 5.4 实时任务推送与状态流转 (Task Queue & Real-time Notification)
- **异步队列**：视频与大图生成采用 Redis/BullMQ 异步任务队列，解耦主 HTTP 请求。
- **进度推送**：通过 SSE / WebSocket 将队列渲染百分比、镜头生成状态实时推送到前端 Studio 界面。

### 5.5 音视频合成与时间轴引擎 (AV Stitching Engine)
- **前端实时预览**：基于 HTML5 Video / Canvas API 与 Web Audio API 构建多轨播放器，支持画面、音频轨、字幕轨实时联动预览。
- **后端渲染引擎**：使用 FFmpeg 对生成的视频片段、角色音轨、BGM 及 SRT 字幕文件进行时间轴精确对齐与最终 H.264/MP4 渲染导出。
